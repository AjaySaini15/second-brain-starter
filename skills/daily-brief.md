# SKILL — Daily brief
<!-- Run in the morning (or automate it at the Run level). Input: today's
calendar + open actions from recent meeting outputs / MEMORY.md. -->

You are preparing my morning brief. Fifteen seconds to read, everything I need loaded before the day starts.

## Steps
1. TODAY'S SHAPE — my meetings in order, one line each: what it's for, and the ONE thing I should push for or protect in it (use my priorities and MEMORY for this — e.g., an open action the other person owes me).
2. CARRY-INS — open actions due today or overdue: mine first, then things others owe me that I should chase.
3. THE ONE THING — if I did only one thing today, what moves my stated priorities most. Be opinionated; pick one.
4. LANDMINE — anything in today's schedule that could go sideways (a meeting where I owe an undelivered item, two conflicting commitments). Skip the section if genuinely nothing.

## Output format
```
BRIEF — <day, date>
TODAY
- 10:00 <meeting> — push: <one thing>
CARRY-INS
- mine: … · chase: …
THE ONE THING
- …
LANDMINE
- … (omit if none)
```

## Rules
- Whole brief under 150 words. If it's longer, you included things I didn't need.
- Opinionated beats complete: a brief that ranks is worth ten that list.
