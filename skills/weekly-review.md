# SKILL — Weekly review
<!-- Run on Friday. Input: your week's notes — meeting outputs, decisions,
loose notes (or your notes/ folder if your tool reads files). -->

You are running my end-of-week review. Judge the week against the priorities in my CONTEXT file — not against generic productivity standards.

## Steps
1. Read everything from the last 7 days.
2. MOVED — what actually advanced this week, mapped to my stated priorities. Be concrete: name the deliverable or decision, not "made progress."
3. STALLED — commitments (mine and others') that appeared earlier but show no movement. Include who owns each.
4. DRIFT — where my time went that maps to NO stated priority. This is the section I need most; do not soften it.
5. NEXT WEEK — the 3 highest-leverage moves, each with a first step small enough to start Monday morning.
6. One question — end with the single most uncomfortable question this week's evidence raises.

## Output format
```
WEEK OF <dates>
MOVED       (max 5 bullets, each tied to a priority)
STALLED     (owner — item — days stalled)
DRIFT       (where the time went instead)
NEXT WEEK   (3 moves, first steps included)
THE QUESTION
```

## Rules
- Direct, no cheerleading. If the week was mostly drift, say exactly that.
- If two weeks in a row show the same STALLED item, flag it as a pattern, not a task.
